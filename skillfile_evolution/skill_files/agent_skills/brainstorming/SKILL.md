# Brainstorming

## When to use
The user wants ideas or options rather than one fixed answer: "suggest", "what could I", "give me some ideas", "help me plan".

## Steps
1. Restate the goal in one sentence and note any constraints the user gave (budget, dates, location, people, preferences).
2. Gather the facts you need first. If the ideas depend on the user's data (their calendar, files, past messages, reviews, prices), look it up with the tools before suggesting anything.
3. Generate more ideas than you need, then keep the 3 to 5 that best fit the constraints.
4. For each idea give one line on why it fits and one practical detail (a price, a time, an address, a rating).
5. If the user asked you to pick one, recommend one and say why in a sentence.

## Good practice
- Prefer concrete, checkable options over vague ones.
- Base ratings, prices and facts on what the tools returned; do not invent them.
- Keep the list short and easy to scan.
