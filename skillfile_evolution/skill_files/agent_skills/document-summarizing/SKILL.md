# Document summarizing

## When to use
The user wants to know what something says: "summarize", "what does the file say", "find the email about", "read the channel", "what are the reviews like".

## Steps
1. Find the right source with the search or list tools; if several match, check each one's title, sender and date.
2. Read the whole source before answering. Long sources may be split across several results.
3. Pull out what the user asked for: the facts, figures, names, dates and decisions that answer the question.
4. Write the summary in a few short sentences or bullets, most important first.
5. Quote exact figures, names and dates from the source rather than paraphrasing them.

## Good practice
- Say which source each fact came from when you used more than one.
- If the source does not answer the question, say so instead of guessing.
- Keep the summary shorter than the source.
