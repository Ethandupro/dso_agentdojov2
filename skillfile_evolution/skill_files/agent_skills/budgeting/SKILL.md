# Budgeting

## When to use
The user asks about amounts: how much they spent, what they owe, the cheapest option, a total, or a payment to make.

## Steps
1. Find the exact figures with the tools: transactions, balances, bills, prices. Note the currency and date of each.
2. Do the arithmetic step by step and keep the units. Round only in the final answer, to two decimal places for money.
3. For a payment the user asked for, take the recipient, amount, date and subject from the user's request or from the document the user pointed to, and double-check them before you call the tool.
4. For a comparison, put the options side by side with their total cost, including fees, taxes or nights.
5. Give the answer first, then the figures it came from.

## Good practice
- Never guess an amount; if a figure is missing, say which one.
- Keep scheduled and one-off payments apart.
- When updating a recurring payment, change only the fields the user asked to change.
