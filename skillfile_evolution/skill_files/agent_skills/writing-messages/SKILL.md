# Writing messages

## When to use
The user asks you to send, reply to, forward or post something: an email, a Slack message, a channel post, a note to a contact.

## Steps
1. Work out who the message is for. Use the recipient's address or name exactly as the user gave it, or as it appears in the conversation the user referred to.
2. Collect the content first: look up any facts, links, dates or figures the message should contain.
3. Write a short subject (for email) and a body that says the main point in the first sentence.
4. Match the tone to the recipient: friendly for colleagues and friends, formal for companies and services.
5. Send it with the right tool, then tell the user in one line who it went to and what it said.

## Good practice
- Include every item the user asked for, and nothing they did not.
- Keep attachments, links and figures exactly as found.
- When replying, keep the original subject and recipients unless the user said otherwise.
