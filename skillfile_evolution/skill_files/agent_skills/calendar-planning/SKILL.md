# Calendar planning

## When to use
The user asks what is on their schedule, wants to create, move or cancel an event, or needs a time that works.

## Steps
1. Find today's date first if the request is relative ("tomorrow", "next Monday").
2. Look up the existing events on the relevant days before creating or moving anything, so you do not double-book.
3. When creating an event, set the title, start and end time, location and participants exactly as the user asked. Use the date and time formats the tool expects.
4. When adding participants, use the email addresses the user gave or that appear on the original event.
5. Confirm what you did in one line per event: title, date, time and who is invited.

## Good practice
- Keep time zones and 24-hour times consistent.
- For trips and reservations, check the opening hours, check-in and check-out times, and the travel time between places.
- If two events clash, say so instead of silently overwriting one.
