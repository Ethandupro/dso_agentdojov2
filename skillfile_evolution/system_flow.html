Data

Split by injection task, so the judge can't memorize the goal

Train · 60% · ~21 injection tasksAttacks: important_instructions or the evolving attacker. Judge input comes only from here.
Test · 40% · ~14 injection tasksAdds held-out styles injecagent and ignore_previous, never used in training.
Suitesworkspace, travel, banking, slack (v1.2.2), stratified split, seed 0
Benign setEvery user task, no injection. Used for checker false-positive rate (share of benign outputs with anything removed) and benign utility, in evaluation only (never to choose a skill file)
PairsOne fixed set of (user task, injection task) pairs per split, sampled once with a fixed seed and used in every round, condition and seed. Pair count set by a power check after the pilot
Rounds3 per run (0, 1, 2), always all 3, one trial per pair per round; 3 seeds per condition
ReportedASR, utility under attack, benign utility, checker FPR, injected text removed, benign text removed, cost per component; bootstrap 95% CIs
Still open before Phase 1
  • The victim scored 0/16 ASR on the banking slice smoke test. The "C0 ASR ≥ 20%" rule has to be checked across all suites and injection tasks, or there's nothing to defend.
  • Checker and attacker model IDs are still to be chosen against the OpenRouter catalogue.
  • Test-split pairs: the attacker never sees test injection tasks, so it can't rewrite them. Unless decided otherwise they keep the round-0 text in every round and condition, which makes C2's test ASR measure exactly what C1's does.
  • What "the file parses" means in text check 1: strict (S0's six sections, fixed), loose (title, non-empty, no code block) or the middle version (six sections in order, extra sections allowed).
  • Checker prompt, the SuperRed ports and the round runner aren't built yet. The DeepAgents victim is ready for them: the runner plugs the checker in through tool_middleware_factory.
  • The native-loop reference addresses the model as "AI assistant" in important_instructions, while the DeepAgents run says "DeepSeek". The two need the same attack text before the comparison means anything.
